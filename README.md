# 甄選所

十校 116 學年度碩士班甄試入口；純靜態網站。

## 本機預覽

`python3 -m http.server 4173 --directory dist`

開啟 http://localhost:4173/ 。無需建置。

## 更新資料

- `dist/schools.json`：學校、官方報名入口、簡章來源。
- `dist/docs/`：2026-10-03 核對的官方 PDF 存檔。更新學年度時，必須重新核對並替換，不可只改年份。
- 台大共同規定與附錄分冊；系所規定連回官方。
- PDF.js 6.3.289 位於 `dist/vendor/`，Apache 2.0 授權隨附。
- 報名在各校官方網站完成，本網站不收集帳號或報名資料。
- 本站為手動核對快照，不會自動更新簡章。
